# PC GAME EMPIRE — MASTER ROADMAP DEFINITIVA 1.0

Questa roadmap sostituisce integralmente la precedente roadmap iper-tecnica.

## Filosofia 1.0

Meno complessità tecnica, più qualità, progressione, divertimento e possibilità concreta di arrivare alla 1.0.

PC GAME EMPIRE è un simulatore/gestionale 2.5D di negozio PC accessibile ma profondo. La progressione centrale è:

**PC scarsi → PC medi → PC belli → PC premium**

parallelamente a:

**Small Shop → Computer Store → Gaming Store → PC GAME EMPIRE**

## Milestone ufficiali

- **A — Assemblaggio PC completo semplificato + compatibilità** — IMPLEMENTING
- **B — Riparazioni + diagnostica + BIOS + benchmark** — PLAYABLE, da completare/polish
- **C — Catalogo hardware + shop + inventario** — PLAYABLE, contenuto da espandere
- **D — Clienti + lavori + recensioni + storyline** — IMPLEMENTING
- **E — Progressione negozio + economia + upgrade** — PLAYABLE, da approfondire

- **H — Tutorial + settings + localization + salvataggi** — PLAYABLE, da completare
- **I — Final QA + performance + polish + Windows release** — NOT STARTED

## Milestone A — criterio COMPLETE

Assemblaggio interattivo tramite drag & drop / snap points / animazioni e feedback, senza micro-simulazione esasperata. Componenti principali: case, motherboard, CPU, cooler/AIO, RAM, GPU, PSU, storage, fans. Ogni installazione deve cambiare visivamente il PC.

Compatibilità minima obbligatoria: socket CPU, motherboard, DDR generation, RAM, GPU length, case/form factor, PSU wattage, cooler/socket, radiator size.

Operazioni volutamente semplificate: viti, standoff e cablaggio interno sono step/animazioni aggregate e non operazioni pin-by-pin.

## Target contenuto 1.0

Circa 200–300 componenti complessivi ben differenziati, con fasce Entry / Mid / High End / Enthusiast. Target artistico: 20–30 case, 100+ artwork componenti, 30–50 props, 15–25 clienti, upgrade negozio visibili, UI art, animazioni e audio dedicato.

## Carriera

Target 10–20 ore curate, strutturate in 5 capitoli: Partenza, Crescita, Gaming, Professional, PC GAME EMPIRE. Dopo il finale si sblocca endgame continuabile e Free Build.

## Escluso come requisito bloccante 1.0

Niente singole viti manuali, pin-by-pin, custom loop watercooling completo, timing RAM estremi, silicon lottery avanzata, simulazione elettrica professionale, oltre 1000 componenti, seconda sede/catena o finanza complessa.

## Definizione di 1.0 completa

Gameplay completo, assemblaggio soddisfacente, catalogo budget→premium, riparazioni, diagnostica, clienti, storyline, progressione negozio, economia, shop, inventario, recensioni, Free Build, RGB, audio, animazioni, UI, salvataggi, settings, IT/EN, QA e build Windows verificata.
